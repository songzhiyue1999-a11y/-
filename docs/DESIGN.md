# 小猫站点视觉系统

## 设计方向

页面采用可直接使用的现代 SaaS 仪表盘界面，以黑白主色、浅色数据卡、清晰排版和轻量组件层级组织内容。页面不包含设备外框、蓝色展示背景或金融内容。

- 深炭色左侧导航，中央和右侧以近白画布、白色内容面板为主。
- 搜索、RAG、选题、文案四个概览指标分别使用浅蓝、浅紫、浅绿、奶油黄背景。
- 使用粗体无衬线标题、深色正文、克制的灰色说明文字和细线图标。
- 面板圆角以 12–18px 为主，保留非常轻的阴影；输入框和按钮有明确边框与焦点态。
- 动效只用于悬停、聚焦和状态切换，并尊重 `prefers-reduced-motion`。

视觉 token 集中在 `src/dashboard-theme.css`。`src/styles.css` 保留原有组件结构、内容尺寸与交互状态，主题文件在它之后加载。新增视觉样式应优先写入主题文件，避免把旧黏土配色带入新组件。

## 品牌与头像

- 页面左上角只显示「小猫站点」，不显示旧标识或英文副标题。
- 示例创作者统一命名为「苹什喵」。
- 侧栏资料卡和小红书预览统一使用 `public/assets/avatar-pingshimiao.png`。头像为用户提供的图片，保持原图内容，圆形裁切时优先让猫的眼睛和厨师帽可见。
- 旧素材 `avatar-creator.png`、`notebook-pencil.png` 仍保留在仓库中，但新主题不引用它们。

## 布局与滚动

保持 3 栏工作台：左侧为流程与草稿导航，中间为阶段式创作区，右侧为模型配置、生成状态和错误提示。桌面设计宽度为 1440px，低于该宽度时允许页面横向滚动；外层不纵向滚动。

- `body` 和 `.app-shell` 高度为视口高度。
- `.sidebar`、`.workspace`、`.config-rail` 各自独立纵向滚动。
- 中栏从标题、四个指标、输入表单开始，下面依次是搜索/RAG、选题、文案/预览、封面 Prompt/结果。
- 指标卡完整显示；各阶段内容采用内容驱动高度，不能截断候选文本、预览和封面结果。
- 右侧模型配置支持本地 CLI 与云端 API 切换，不因样式改动隐藏字段或检测入口。

在 1440×900 和 1440×720 视口检查三栏滚动、头像裁切、表单、右侧状态、空状态和底部内容。

## 组件与状态

- 主操作为深炭色实心按钮，次操作为白底细边框按钮；薄荷绿用于选中态和成功状态。
- 右侧模型切换采用淡灰轨道与浅绿选中项。
- 搜索结果、RAG 条目、选题、文案和 Prompt 的选中态使用绿色边框和浅绿背景。
- 空状态使用紧凑浅灰面板；错误提示使用柔和浅粉底，成功提示使用浅绿底。
- 输入框必须保留清晰的焦点轮廓，图标使用 `lucide-react` 细线图标。
- 所有按钮、输入、文本和列表保持代码原生，不能把页面截图当作 UI 使用。

## 封面设计边界

封面 Prompt 和封面结果区默认不出现真人、脸、手和动物。可以使用衣物、包鞋、文具、色卡、桌面、空间、植物或花材。示例创作者头像中的猫只用于账户身份与文章作者标识，不用于封面生成内容。
